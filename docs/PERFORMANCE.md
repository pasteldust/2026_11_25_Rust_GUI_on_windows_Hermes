# 性能

## 目標

| 項目 | 目標 | 測定方法 |
| --- | --- | --- |
| 起動時間 | 3 秒以内 | `--self-test` が出力する「初期化〜最初の描画完了」までの経過時間 |
| 常駐メモリ | 500 MB 以下 | Windows のタスクマネージャ、または `--self-test` が記録するピーク作業セット |
| クラッシュ | ゼロを目標 | CI の E2E とテストで継続的に確認 |

## 計測の方法

`paint-app --self-test <出力先>` は実行結果と一緒に次を JSON で出力する。

```json
{
  "startup_ms": 0,
  "draw_ms": 0,
  "save_ms": 0,
  "load_ms": 0,
  "peak_memory_mb": 0
}
```

CI（`.github/workflows/ci.yml` の `E2E (windows-latest)`）がこの JSON を成果物として保存するので、
リリースごとの数値を追える。

## 設計上の配慮

- キャンバスの合成結果は ViewModel がキャッシュし、変更があったときだけ作り直す。
- 履歴は変更矩形の差分のみを保持する（全面スナップショットを積まない）。
- レイヤーの合成は行単位で走査し、不要な分岐を避ける。
- 画像の上限は 16384px（[`paint_core::pixel_buffer::MAX_DIMENSION`]）。
